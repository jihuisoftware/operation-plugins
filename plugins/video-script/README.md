# 短视频分镜

在 Hermes 对话里粘贴中文定稿，指定 30 秒或 60 秒，得到一张可以复制给拍摄同事的分镜表。时长默认 30 秒。需要配置 Hermes 文本模型。

## 安装和调用

在桌面端「扩展工具 → 插件 → 从 Git 安装」中选择智能体插件，安装并启用。本地开发可将仓库地址换为本地 Git 仓库的 file URL，安装器读取已提交版本。

```text
https://github.com/jihuisoftware/operation-plugins.git#plugins/video-script
```

对 Agent 说「用短视频分镜插件，把下面这篇定稿改成 30 秒的拍摄表」，随后粘贴正文。工具 `video_script_generate` 接受必填的 `body`、可选的 `title` 和 `duration_seconds`。结果包含总时长、带起止秒数的 `shots` 和可复制的 `markdown`。

每镜附一段可以回到正文定位的引文。编辑可据此核对数字、专名和限定条件。工具按每秒五个口播单位筛查明显过长的镜头，汉字和数字按字计，连续英文字母按词计。实际拍摄前请逐镜计时试读。模型输出有误时工具会带着具体问题修订一次，仍未通过会返回原因。

## 同一篇定稿的两种拍法

以下示范取自本仓库的封面设计说明。

> 点击「生成封面」后，设计 Agent 根据标题、正文、受众和渠道选择版式。请配置文本模型及视觉分析模型。AI 底图可选；未配置生图模型时使用插件自带的本地样式。
>
> 插件可复用已授权底图，或按主题预算生成新底图。首检使用真实竖版成品；最多再修订两轮。可在「设计封面 → 查看评审详情」查看每轮候选和修改原因。

### 30 秒：看一次封面评审

| 时间段 | 画面建议 | 口播 | 屏幕字幕 | 原文依据 |
| --- | --- | --- | --- | --- |
| 0–8 秒 | 录屏，点击「生成封面」 | 点一下生成封面，看看这篇稿子会用什么版式。 | 生成封面 | 点击「生成封面」后，设计 Agent 根据标题、正文、受众和渠道选择版式。 |
| 8–18 秒 | 展示竖版成品，停在标题处 | 第一轮评审看的是这张竖版成品。需要修改时，最多再修订两轮。 | 先看成品，再修订 | 首检使用真实竖版成品；最多再修订两轮。 |
| 18–30 秒 | 打开评审详情，依次指向候选图和修改原因 | 想知道为什么改？打开设计封面里的评审详情，对着每轮候选看修改原因。 | 查看每轮候选和修改原因 | 查看每轮候选和修改原因 |

### 60 秒：从模型配置拍到评审详情

| 时间段 | 画面建议 | 口播 | 屏幕字幕 | 原文依据 |
| --- | --- | --- | --- | --- |
| 0–10 秒 | 在设置页依次指向两项模型配置 | 开始做封面前，先配置文本模型和视觉分析模型。 | 准备两项模型配置 | 请配置文本模型及视觉分析模型。 |
| 10–23 秒 | 展示稿件标题和正文，再点击生成 | 点生成封面后，设计 Agent 会结合标题、正文、受众和渠道来选版式。 | 根据稿件选版式 | 根据标题、正文、受众和渠道选择版式 |
| 23–35 秒 | 展示一张本地样式的封面 | 如果还没配置生图模型，也能用插件自带的本地样式。 | 可使用本地样式 | 未配置生图模型时使用插件自带的本地样式 |
| 35–46 秒 | 指向已授权底图，再展示生成底图的示例 | 已经有授权底图可以复用。想换一张，也可以按主题预算生成。 | 复用或生成底图 | 插件可复用已授权底图，或按主题预算生成新底图。 |
