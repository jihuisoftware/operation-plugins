# 封面设计
与支持 operations.coverDesigner 的运营桌面版配合使用。在「扩展工具 → 插件 → 从 Git 安装」安装并启用本包的后台和桌面组件。在待审核稿的「封面与审核 / 设计封面」或写作草稿的「设计封面」使用。

上传成品保留比例。上传底图或生成 AI 底图后可裁切、排版中文标题，输出 1080 × 1440。图片仅在确认后应用。AI 底图使用当前后台配置，重新排版不重复付费。自动生成请在主题计划选择「插件单封面」，保存风格与每日额度。

后端 cover_generate 处理宿主创建的一次性本地交换目录，生成、素材授权、主题额度和稿件修订归所属运营任务管理。插件使用 Hermes 运行环境的 Pillow 和中文字体。界面入口是原生 ES 模块，无前端构建步骤。
